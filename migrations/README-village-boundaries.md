# อาณาเขตพื้นที่รับผิดชอบแต่ละหมู่

สถานะเริ่มต้น: ยังไม่มีข้อมูลแนวเขตจริง ใน HOSxP ที่ตรวจเมื่อ 8 กันยายน 2569 ตาราง gis_village และ village_map_point ไม่มีรายการ จึงไม่ได้สร้างหรือประมาณเส้นจากตำแหน่งบ้าน

## วาดร่าง

1. เข้าหน้าแผนที่ด้วยบัญชี staff/admin แล้วเปิด “อาณาเขตหมู่บ้าน” ที่มุมขวาบน
2. เลือกหมู่ ระบุชื่อและที่มา/ผู้จัดทำร่าง แล้วกด “เริ่มวาดแนวเขต”
3. คลิกจุดตามลำดับรอบพื้นที่อย่างน้อย 3 จุด ไม่ต้องคลิกจุดแรกซ้ำ ใช้ “ย้อนจุดล่าสุด” เมื่อคลิกผิด สามารถพับเครื่องมือเพื่อเพิ่มพื้นที่วาดได้
4. กด “บันทึกร่าง” ระบบตรวจพิกัด วงปิด พื้นที่เป็นศูนย์ และเส้นตัดตัวเองก่อนบันทึก
5. ส่งออก GeoJSON เก็บไว้ และนำแนวเขตไปตรวจร่วมกับผู้รับผิดชอบหมู่บ้าน/รพ.สต./อบต.

ร่างเป็นข้อมูลใน localStorage แยกตามบัญชีและเบราว์เซอร์ ไม่ได้ส่งเข้า Supabase หรือ HOSxP ผู้ใช้อื่นยังไม่เห็นร่าง การล้างข้อมูลเบราว์เซอร์อาจทำให้ร่างหาย จึงควรส่งออกไฟล์เสมอ รายการหมู่ที่มีร่างบนเครื่องนี้จะแสดงทับแนวเขตส่วนกลางเฉพาะบนเครื่องนี้

การแก้ร่างใช้วาดใหม่ทั้งวง หรือแก้ไฟล์ GeoJSON ภายนอกแล้วนำเข้า ไม่รองรับลากย้ายจุดเดิมในรุ่นนี้ การนำเข้าและส่งออกจะยังระบุ status=draft และไม่ถือเป็นการรับรองแนวเขต

## แนวเขตที่ใช้ร่วมกัน

หลังผู้รับผิดชอบตรวจสอบแล้ว ให้ผู้ดูแลใส่ FeatureCollection ลง `public/village-boundaries.geojson` แล้ว commit/deploy เว็บ ผู้ใช้ทั้งหมดจะเห็นชุดเดียวกันจากไฟล์นี้ เก็บที่มาใน properties.source เสมอ ควรระบุหน่วยงานและวันที่ตรวจสอบ แนวเขตส่วนกลางไม่ได้หมายถึงแนวเขตทางกฎหมายโดยอัตโนมัติ

รองรับ Polygon และ MultiPolygon ใน WGS84/EPSG:4326 โดยพิกัดเรียง [longitude, latitude] และ properties.moo เป็นหนึ่งในหมู่ที่ระบบรับผิดชอบ กำหนดหนึ่ง Feature ต่อหมู่ หากหมู่มีหลายพื้นที่แยกกันให้ใช้ MultiPolygon ไม่รับ KML โดยตรง ไฟล์นำเข้าไม่เกิน 2 MB, 100 Features, 1,000 จุดต่อวง และรวม 10,000 จุด

properties ประกอบด้วย moo, name, source, updated_at; ไม่ต้องใส่ชื่อบุคคล เลขบัตร หรือพิกัดบ้านลงไฟล์แนวเขต เครื่องมือตรวจโครงสร้างพื้นฐาน แต่ไม่ได้ตรวจความถูกต้องทางปกครอง การซ้อนทับระหว่างหมู่ หรือตำแหน่งช่องว่างภายใน polygon ต้องให้ผู้รับผิดชอบตรวจสอบกับแนวเขตอ้างอิงจริง

บนแผนที่สามารถเปิด/ปิดชั้นอาณาเขต และกดชื่อหมู่เพื่อซูมดูพื้นที่ได้ สีแนวเขตใช้แยกหมู่ ส่วนสีหมุดบ้านยังใช้แสดงกลุ่มข้อมูลสุขภาพตามระบบเดิม
